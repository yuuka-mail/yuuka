# 标志

信封小怪和字标的成品 SVG，由独立的美术制作流程导出，这里只放副本：不要手改，也不要重画。
为什么长这样、用在哪，见 [§14](../../../docs/design/brand.md)。

| 文件                                            | 用途                                           |
| ----------------------------------------------- | ---------------------------------------------- |
| `mark.svg`、`mark-reverse.svg`、`mark-mono.svg` | 单独的小怪：彩色、深底反白、单色               |
| `horizontal-*.svg`、`stacked-*.svg`             | 小怪加字标的横排、竖排组合，比例固定，整体缩放 |
| `wordmark.svg`、`wordmark-reverse.svg`          | 单独的字标                                     |

[`web/public/favicon.svg`](../../public/favicon.svg) 由小怪几何派生：居中放在方形画布上，暗色时切换成反白版。
